# Hi-Z 深度金字塔与遮挡剔除（gpu-hiz-build）

## 题面

接入 Hi-Z 遮挡剔除后，远景物体一闪一闪、边缘还漏检：层级归约用了平均深度，块内远表面被抹平而误判遮挡；奇数宽高向下取整，右列和下边界整块丢失；金字塔停在 2×2 不再生成 1×1，选层与最粗层采样错位；`pick_level` 对 `max(w, h)` 向下取整，采样到过细层而漏掉更远遮挡；深度比较用 `>` 而不是 `>=`，贴面物体在相等深度上逐帧闪烁；查询矩形不做裁剪，负坐标和越界索引直接读图外；重叠查询合并时取交集，查询覆盖不足而漏判；深度越界不校验，NaN 沿最大深度传播；批量构建共用同一条 mip 链，后一帧覆盖前一帧；`levels <= 0` 不校验，构建时出现除零。hiz/buffer.py 是核心，tests/test_buffer.py 15个红。要修的是：层级按 2×2 取最大深度并向上取整奇数边；每层继续归约到 1×1 且尺寸严格递减；`pick_level` 用向上取整并钳到可用层；遮挡比较用带 1e-6 容差的 `>=` 且只读矩形覆盖的边界像素；矩形先裁剪到图内；重叠查询合并为轴对齐包围盒；逐像素校验深度范围并拒绝 NaN；批量每帧使用独立 mip 链且先全量校验、失败整体回滚；`levels <= 0` 抛 `HizError`。

## 运行方式

在仓库根目录执行：

```bash
python -m pytest tests -q
```

初始状态必须恰好是 `15 failed`，不能出现 collection/import/syntax error。修复 `hiz/buffer.py` 后，同一命令应全部通过。
